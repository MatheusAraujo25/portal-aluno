Git & GitHub no Windows

Do Zero ao seu primeiro Push

← Voltar para Home

1. Preparando o Ambiente

Primeiro, precisamos instalar o Git no Windows:

  • Baixe o instalador em: git-scm.com
  • Durante a instalação, mantenha as opções padrão, mas certifique-se de selecionar o Git Bash.

2. Configurando sua Identidade

Abra o Git Bash ou o Terminal e execute os comandos abaixo com seus dados do GitHub:

git config --global user.name "Seu Nome" git config --global user.email "seuemail@exemplo.com"

3. Primeiro Push (Subindo seu código)

Dentro da pasta do seu projeto mobile, siga esta sequência:

# Inicia o repositório

git init

# Conecta ao GitHub (substitua pelo link do seu repo)

git remote add origin https://github.com/usuario/projeto.git

# Adiciona, Comita e Envia

git add . git commit -m "Primeiro commit" git push -u origin main

4. Mantendo-se atualizado (Pull)

Sempre que trabalhar em grupo ou trocar de computador, baixe as novidades:

git pull origin main

Dica: Use o Git Credential Manager (já vem no instalador) para não precisar digitar senha toda hora.
