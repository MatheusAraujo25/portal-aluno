🔑 Autenticação Sem Senha

Configurando o Git Credential Manager no Windows

🛠️ Como Ativar (Passo a Passo)

Passo 1

Abra o seu Git Bash (ou Terminal do Windows).

Passo 2

Digite o comando abaixo para ativar o gerenciador de credenciais:

git config --global credential.helper manager

Resultado:

Na próxima vez que você der um git push, abrirá uma janela do Windows pedindo para você logar no navegador. Logue uma única vez e pronto!
