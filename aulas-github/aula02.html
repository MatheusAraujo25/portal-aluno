🔑 Autenticação Sem Senha

Configurando o Git Credential Manager no Windows

← Voltar para Trilhas Git

🧐 Cansado de digitar a senha?

Sempre que você faz um git push ou pull, o Git pede suas credenciais. No Windows, podemos automatizar isso usando o GCM (Git Credential Manager).

🛠️ Como Ativar (Passo a Passo)

Passo 1

Abra o seu Git Bash (ou Terminal do Windows).

Passo 2

Digite o comando abaixo para ativar o gerenciador de credenciais:

git config --global credential.helper manager
Passo 3

Na próxima vez que você der um git push, abrirá uma janela do Windows pedindo para você logar no navegador. Logue uma única vez e pronto!

💡 Dica de Mestre

Onde ficam guardadas?

O Windows guarda essas senhas no "Gerenciador de Credenciais" do próprio Painel de Controle. Se você trocar de senha no GitHub, é lá que você deve apagar a antiga.
