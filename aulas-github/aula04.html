🚀 O Ciclo de Vida do Código

Entendendo o Add, Commit e Push na prática.

📦 Os 3 Estados do Git

  • Working Directory: Sua mesa de trabalho (arquivos alterados).
  • Staging Area (Add): Colocar o item dentro da caixa de envio.
  • Repository (Commit): Lacrar a caixa e colocar um selo com data enome.

💻 Comandos na Ordem Correta

Lembre-se essa é a base do git

git add . - Prepara todos os arquivos alterados para o envio.

git commit -m "texto" - Cria uma versão local. Use mensagens claras como: "Ajuste no layout do login".

git push origin main - Envia sua "caixa lacrada" para o servidor do GitHub


⚠️ Erro Comum:

Esquecer o Commit

Muitos alunos tentam dar Push direto após o Add. Lembre-se: O Push envia Commits, não arquivos soltos!
