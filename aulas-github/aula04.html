🌳 O que é uma Branch?

Imagine que o seu código é o tronco de uma árvore (a main). Uma Branch é um galho que sai desse tronco.

Você pode testar coisas novas no galho. Se der errado, o tronco continua intacto!

🛠️ Comandos de Ramificação

git checkout -b nome

Cria uma nova branch e já "pula" para dentro dela.

git branch

Lista todas as branches. A que estiver com asterisco (*) é a que você está usando.

git checkout main

Volta para a branch principal (o tronco da árvore).

git merge nome

Une as alterações do seu "galho" de volta ao tronco principal.

💡 Dica para o TCC

Organização em Grupo

Cada aluno deve ter sua própria branch (ex: dev-matheus). Nunca façam commits direto na main ao mesmo tempo para evitar conflitos!
